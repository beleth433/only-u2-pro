# Only U2 Pro — CRM Управление прокатом электровелосипедов (MVP)

Готовый прототип веб-CRM системы для презентации и продажи клиентам, занимающимся арендой электротранспорта курьерам (Яндекс Еда, Самокат, Купер, Достависта).

---

## 🚀 Быстрый запуск

### Запуск сервера:
```bash
cd C:\Users\BXLETH\Desktop\courier-bike-crm
npm start
# или: node server.js
```

### Как открыть:
* **На этом компьютере**: [http://localhost:3000](http://localhost:3000)
* **На смартфоне (в одной Wi-Fi сети)**: [http://192.168.0.101:3000](http://192.168.0.101:3000)

## ⚙️ Что изменено по требованиям:
1. **Убраны проценты заряда АКБ**: никакой фантастики и недостоверных процентов — только реальный физический учет наличия батарей на складе.
2. **Простой складской учет АКБ**:
   * Характеристики (60V 21Ah, 60V 30Ah увеличенная, 48V 18Ah).
   * Статус: `Свободен (на складе)` или `Выдан к байку #...`.
   * Примечания и возможность добавить новую батарею.
3. **Велопарк**: к каждому байку прикреплен номер и характеристики выданного аккумулятора.
4. **Убран «Быстрый своп»**: удалены все лишние механики.
5. **Ребрендинг**: проект переименован в **Only U2 Pro**.
